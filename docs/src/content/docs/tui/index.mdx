title: Chit TUI
description: A terminal user interface for the Chit messaging server. Built with Go and the Charmbracelet Bubble Tea ecosystem.
---

import { Card, CardGrid } from '@astrojs/starlight/components';

A terminal client for Chit. It gives real-time messages, threaded
conversations, Markdown rendering and themes that the user can change, all in
the terminal. The TUI uses Go and the Charmbracelet Bubble Tea ecosystem. Its
code is in the Chit monorepo under `clients/chit-tui`.

The interface has a two-pane layout: the chat history on top, the message
input below, and an action bar with clickable buttons along the bottom. All
navigation goes through the unified palette. Press `Ctrl+K` to go to a
channel, find a person, run a slash command or search the messages.

To start, read [Install Chit TUI](/chit/tui/getting-started/installation/).
The [Keybindings reference](/chit/tui/reference/keybindings/) lists all keys.

<CardGrid>
  <Card title="Real-Time Messaging" icon="rocket">
    The TUI keeps the WebSocket open with keepalive pings. If the WebSocket closes, the TUI connects again automatically, with backoff. A message appears immediately when someone posts it. After each reconnect, the TUI reads the channel again, so it shows all messages sent during the gap.
  </Card>
  <Card title="Unified Palette" icon="magnifier">
    One overlay (Ctrl+K) for all tasks. It sorts the channels by unread activity. Type `@` to find people, `/` to run slash commands, and `?` to search messages. Type `??` to search all channels.
  </Card>
  <Card title="Threaded Conversations" icon="comment">
    Press Enter on a post to open its thread full-screen. Reply from the regular input box; Esc returns to the channel.
  </Card>
  <Card title="Mouse Support" icon="setting">
    Click action-bar buttons and posts, select palette rows, wheel-scroll history, and drag to select lines to copy — while everything stays fully keyboard-drivable.
  </Card>
  <Card title="Markdown Rendering" icon="document">
    Posts rendered with Glamour for rich terminal output — code blocks, links, emphasis, and more.
  </Card>
  <Card title="Customizable Themes" icon="sun">
    Eight bundled themes in dark and light pairs: Tokyo Night, Catppuccin, Kanagawa and Nightfox. The theme can follow the appearance of the terminal. The user can also add TOML themes. `Ctrl+T` changes the theme at once, with no restart. See [Themes](/chit/tui/guides/themes/).
  </Card>
  <Card title="Agents and Bots" icon="puzzle">
    Badges mark the posts of agents and bots, a post that a client made for a person, and provenance. A line shows while an agent writes a reply. See [Agents and Bots](/chit/tui/guides/agents-and-bots/).
  </Card>
  <Card title="Attachments" icon="document">
    `/attach` sends an image with alt text. Each file of a post has one line, and `s` in the post details saves the files. See [Attachments](/chit/tui/guides/attachments/).
  </Card>
  <Card title="Tags" icon="list-format">
    Private tags and channel tags. The owner renames and deletes a tag in the tag picker, and `/chtag` tags and finds channels. See [Tags](/chit/tui/guides/tags/).
  </Card>
  <Card title="Unread Badges" icon="information">
    Per-channel unread and mention counts surface in the palette, which sorts the most active channels to the top.
  </Card>
  <Card title="Post Tagging" icon="list-format">
    Tag posts with `#tag` syntax or the tag picker overlay. Search by tags to find relevant conversations quickly.
  </Card>
  <Card title="Keyboard First" icon="laptop">
    Every mouse action also has a key: copy with `y`, edit with `e`, delete with `d d`, pin with `p`. Press `?` for the built-in help overlay.
  </Card>
</CardGrid>
