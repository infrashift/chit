---
title: Themes
description: Built-in color themes for Chit TUI.
---

Chit TUI ships with four built-in themes. Set the `CHIT_THEME` environment variable to switch between them.

## Tokyo Night (default)

The default theme when `CHIT_THEME` is unset. Cool blue tones with purple accents, inspired by the [Tokyo Night](https://github.com/folke/tokyonight.nvim) color scheme.

```bash
export CHIT_THEME=tokyo-night
```

| Element | Color |
|---------|-------|
| Background | `#1a1b26` |
| Foreground | `#c0caf5` |
| Accent | `#7aa2f7` |
| Username | `#bb9af7` |
| Error | `#f7768e` |
| Success | `#9ece6a` |
| Warning | `#e0af68` |

## Catppuccin Mocha

A soothing pastel palette from [Catppuccin](https://github.com/catppuccin/nvim). Lavender blues and mauve purples on a warm dark base.

```bash
export CHIT_THEME=catppuccin
```
