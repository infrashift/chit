## Prerequisites

| Dependency | Version | Purpose |
|---|---|---|
| Go | 1.22+ | Build the server binary |
| Podman | 4.0+ | Run infrastructure containers |
| PostgreSQL | 17 | Primary data store (runs in the pod) |
| golang-migrate | latest | Apply database migrations |

## Build from source

```bash
git clone https://github.com/infrashift/chit.git
cd chit
make build
```

This produces `bin/chitd` — the main server binary.

## Build the MCP server

```bash
make build-mcp
```

This produces `bin/chit-mcp` — an MCP server for AI agent integration.

## Build the other binaries

```bash
make build-reconcile   # bin/chit-reconcile — pushes CUE roles/actors into Keto
make build-claude      # bin/chit-claude — headless Claude Code bridge
make build-all         # everything at once
```

See [Headless Claude Code](/chit/deployment/headless-claude/) for setting up the
bridge.

## Build the container image

```bash
podman build -t chit:latest -f deploy/Containerfile .
```

## Run tests in a container

The test Containerfile builds a UBI9-based image with the Go toolchain and runs
all unit tests inside it. No PostgreSQL or external services are required — every
test uses in-memory mocks.

```bash
make test-container
```

This builds the `chit-test:latest` image (compile-gating at build time) and then
runs `go test -race -count=1 -v ./...` inside it.

To run a specific test or package, override the default `CMD`:

```bash
podman run --rm chit-test:latest go test -run TestSpecific ./internal/model/...
```

To build with a different Go version:

```bash
podman build --build-arg GO_VERSION=1.25.4 \
  -t chit-test:latest -f Containerfiles/Containerfile.test .
```

## Verify the build

```bash
./bin/chitd --help
```
