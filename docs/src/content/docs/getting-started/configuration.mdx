---
title: Configuration
description: Environment variable configuration for the Chit server.
---

Chit uses [koanf](https://github.com/knadh/koanf) to load configuration from
environment variables. All variables use the `CHIT_` prefix.

Copy the example file to get started:

```bash
cp .env.example .env
```

## Variable Groups

### Server

| Variable | Description |
|---|---|
| `CHIT_LISTEN_ADDRESS` | Address and port to bind (e.g., `:8065`) |
| `CHIT_ALLOWED_ORIGINS` | Comma-separated CORS/WebSocket origin allowlist; default `*` (dev only, logs a warning) |
| `CHIT_LOG_LEVEL` | Log verbosity: `debug`, `info`, `warn`, `error` |
| `CHIT_LOG_FORMAT` | Log output format: `json` or `text` |

### Database

| Variable | Description |
|---|---|
| `CHIT_DATABASE_URL` | PostgreSQL connection string |
| `CHIT_DB_MAX_OPEN_CONN` | Maximum open connections |
| `CHIT_DB_MAX_IDLE_CONN` | Maximum idle connections |

### Pub/Sub

| Variable | Description |
|---|---|
| `CHIT_PUBSUB_BACKEND` | Backend: `pgnotify` (default) or `nats` |
| `CHIT_NATS_URL` | NATS server URL (when using NATS backend) |

:::note
The pub/sub layer currently serves the MCP agent event feed (thin event
envelopes on the `chit_events` topic, polled by `chit-mcp`). WebSocket
fan-out is single-node — chitd does not yet consume the topic for
multi-node delivery.
:::

### Ory Stack

| Variable | Description |
|---|---|
| `CHIT_TRUSTED_PROXY_HEADER` | Header containing the authenticated user ID |
| `CHIT_TRUSTED_PROXY_SECRET` | When set, `X-User-Id` is only trusted if the request carries a matching `X-Proxy-Secret` header (injected by Oathkeeper); recommended in production |
| `CHIT_KRATOS_ADMIN_URL` | Kratos admin API URL |
| `CHIT_KETO_READ_URL` | Keto read API URL |
| `CHIT_KETO_WRITE_URL` | Keto write API URL |

### ZincSearch

| Variable | Description |
|---|---|
| `CHIT_ZINCSEARCH_URL` | ZincSearch server URL |
| `CHIT_ZINCSEARCH_USER` | ZincSearch username |
| `CHIT_ZINCSEARCH_PASSWORD` | ZincSearch password |

### WebSocket

| Variable | Description |
|---|---|
| `CHIT_WS_PING_INTERVAL` | Interval between WebSocket ping frames |
| `CHIT_WS_WRITE_TIMEOUT` | Write deadline for WebSocket messages |

### Cache

| Variable | Description |
|---|---|
| `CHIT_CACHE_SIZE` | Maximum number of entries in the LRU cache |
| `CHIT_CACHE_TTL` | Cache entry time-to-live |

### MCP Agent

| Variable | Description |
|---|---|
| `CHIT_MCP_SERVER_URL` | chitd base URL the MCP server connects to (default `http://localhost:8065`) |
| `CHIT_MCP_AGENT_KRATOS_ID` | Kratos identity ID of the agent user chit-mcp acts as (e.g., the seeded `chit-agent`) |
| `CHIT_MCP_PROXY_SECRET` | Must match `CHIT_TRUSTED_PROXY_SECRET` when chitd requires it |

### Slash Commands & Webhooks

| Variable | Description |
|---|---|
| `CHIT_COMMANDS_CUE_DIR` | Directory with CUE definitions for commands, roles, and actors (default `auth`) |
| `CHIT_AUDIT_LOG_PATH` | File path for the slash-command audit log |
| `CHIT_WEBHOOK_ENABLED` | Enable the CloudEvents webhook dispatcher (default `false`) |
| `CHIT_WEBHOOK_URL` | Destination URL for webhook deliveries |
| `CHIT_WEBHOOK_SECRET` | Shared secret used to sign webhook deliveries |
| `CHIT_WEBHOOK_WORKER_COUNT` | Concurrent webhook delivery workers (default `4`) |
| `CHIT_WEBHOOK_QUEUE_SIZE` | In-memory webhook queue size (default `1024`) |
| `CHIT_WEBHOOK_TIMEOUT_SEC` | Per-delivery HTTP timeout in seconds (default `10`) |

`.env.example` is the source of truth for the complete variable list. See the
[Configuration Reference](/chit/reference/configuration/) for the
complete table with types and defaults.
